Given an array of n integers, where every integer is between 1 and n inclusive, return the first number that appears more than once when reading the array from left to right.

If multiple numbers are repeated, return the number whose second occurrence appears earliest.

If no duplicate exists, return -1.

You are allowed to modify the input array.

Example 1:

```
Input:  [2, 1, 5, 2, 3, 3, 4]
Output: 2
```

Example 2:

```
Input: [2, 1, 5, 3, 3, 2, 4]
Output: 3
```
